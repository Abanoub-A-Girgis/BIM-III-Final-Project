# User guide

Open a non-family Revit project. **Create Schedules** selects defaults and marks existing schedules. **Excel Sync** validates the full workbook before modifying Revit. Categories and parameters use explicit `BuiltInCategory`/`BuiltInParameter` names. **Export Schedules** selects actual schedule elements, then a writable folder; collisions receive `(2)`, `(3)`, and so on. **Model Audit** opens a sortable table. Logs are stored under `%LocalAppData%\RevitDocumentationAutomation\Logs`.
